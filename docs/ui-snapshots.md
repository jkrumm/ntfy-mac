# UI snapshots

`FORCE=1 make snapshots` (refused without `FORCE=1` or `CI=true`, see Gate) builds the app with `SNAPSHOT_HARNESS` (own derived-data path `.build/xcode-snap`, so the release app never contains the harness or its fixtures) and runs it with `--ui-snapshot`: every window and the popover, drawn offscreen over in-memory fixtures in light and dark, into `.build/snapshots/<surface>-<state>-<light|dark>-<WxH>.png` (`SNAP_DIR` overrides it, `SNAP_ONLY=<substring>` draws one entry). It needs no display, permission or real data (temp `HOME`, no config, Keychain, network, notifications or visible windows). Use it to look at a UI change; read the PNGs, there is no golden file and no assertion. What is drawn is `SnapshotPlan` (`Sources/NtfyAppLogic`, a test keeps it covering every window and settings section); the harness code is `App/Sources/Snapshots/`. The sidebar's glass is approximated, because AppKit cannot draw it offscreen.
